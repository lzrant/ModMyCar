# Kenney Car Kit Models

These vehicle models are from Kenney's Car Kit, mirrored from:

- Source: https://www.kenney.nl/assets/car-kit
- Mirror used for local import: https://github.com/ETdoFresh/kenney.nl/tree/master/carkit_v1.4
- License: Creative Commons CC0

The app uses these GLB assets as the base vehicle models and applies detected
modification overlays in Three.js.
